# 标书查重专家

标书查重专家帮助您对比多份标书，发现相似内容和关键词命中，辅助开展标书审查。

## 主要能力

- **标书查重**：以一份标书为主文件，与 1 至 10 份标书进行对比。
- **相似内容分析**：查看各对比文件的相似度、重复片段及相关上下文，帮助定位需要复核的内容。
- **关键词检测**：根据您提供的关键词，查看标书中的命中情况。
- **进度与结果查询**：通过任务号查询查重进度，并打开查重结果页；可查看时也可进入对应的文件对比页面。

## 使用方式

告诉专家您希望对比的主标书和其他标书，并按提示提供文件路径；如需检测关键词，一并提供即可。提交后，专家会返回任务信息和结果页链接。查重完成后，您可以继续询问相似内容、关键词命中或指定文件的对比结果。

支持 DOCX、带可提取文字层的 PDF 和 UTF-8 编码 TXT 文件。部分对比详情可能需要按照页面提示解锁。相似度和重复片段仅供参考，具体情况应结合上下文进行人工复核。
