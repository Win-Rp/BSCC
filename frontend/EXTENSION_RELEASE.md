## 推荐商店文案

### 名称

标书查重助手

### 一句话简介

面向投标文件的标书查重与围标风险排查插件，点击即可进入上传查重工作台。

### 商店短描述

快速进入标书查重工作台，上传投标文件并查看相似度排行、风险摘要与原文对比证据。

### 商店详细描述

标书查重助手适合工程企业、乙方商务团队和投标复核人员使用。插件提供一个更直接的浏览器入口，帮助你快速进入标书查重工作台，完成上传、查重、结果复核与证据查看流程。

你可以使用它完成以下工作：

- 上传 1 份主标书 A 与 1 到 10 份对比标书 B
- 查看相似度排行、风险摘要和高风险文件优先级
- 查看完全重复、改写相似、语义接近等命中结果
- 进入原文对比页核验命中证据与上下文
- 辅助排查围标风险、高重复片段与敏感关键词

适合的使用场景包括：

- 投标提交前的最终复核
- 多版本标书或代理稿的相似风险排查
- 工程企业内部的技术标、商务标交叉检查
- 商务团队在短时间内完成首轮筛查与修改定位

插件本身不主动读取你当前浏览的网页内容，也不会在未触发业务操作时采集无关页面信息。它主要作用是作为标书查重工作台的快捷入口，并与线上服务协同完成分析流程。

### 商店亮点文案

- 开箱即用：点击图标直达上传查重页
- 聚焦标书场景：不是通用文章查重，而是面向投标文件复核
- 结果可复核：支持相似度排行、风险摘要与原文证据查看
- 适合团队协作：方便工程团队、商务团队快速锁定高风险内容

### 审核备注可用文案

该扩展用于打开并使用 `https://biaoshu.mxitx.com` 提供的标书查重服务。扩展不会主动读取任意网页内容，仅在用户主动点击扩展图标后打开独立页面，并与站点接口通信完成文件上传、任务查询和结果展示。

## Chrome 提交流程

1. 执行 `npm run build:crx`
2. 将 `frontend/dist-crx` 压缩为 zip
3. 登录 Chrome Web Store Developer Dashboard
4. 上传 zip
5. 填写名称、简介、截图、隐私政策链接
6. 提交审核

## Edge 提交流程

1. 复用同一个 zip
2. 登录 Microsoft Edge Add-ons Dashboard
3. 填写相同的商店资料
4. 提交审核

## 建议自测项

- 点击扩展图标是否直接进入上传页
- 上传文件与创建任务是否正常
- 结果页与对比页是否正常切换
- 接口异常时是否会白屏
- 多次打开扩展是否稳定
